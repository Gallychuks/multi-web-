# BrightCare Medical Centre — Website Demo

Responsive hospital/clinic website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive mobile navigation
- Department/service cards and sample doctor profiles
- Appointment request form with validation and summary
- Preferred date cannot be earlier than today
- Accessible status message and reduced-motion support
- Contact section and emergency guidance

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## Important
This is a front-end portfolio demo, not a real hospital system. Clinician names, contact details and services are fictional placeholders. Appointment requests are not sent or stored. Do not enter real patient data. A real deployment needs a secure backend, access controls and a reviewed privacy process.

## Suggested repository
`brightcare-hospital-website`

## Publish
Upload these files to a public GitHub repository and enable GitHub Pages in repository settings to host the static website.
