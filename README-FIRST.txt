STUDIO ELEVEN — 11 INDEPENDENT WEBSITE PROJECTS

The root index.html is a stylish directory/launcher that links to the 11 project folders.
Open index.html to browse the collection locally. It includes responsive styling, search and category filters.

Each project is kept in its own folder and contains its own index.html, styles.css and script.js:
- healthcare-website
- technology-website
- construction-website
- real-estate-website
- education-website
- commerce-website
- hospitality-website
- finance-website
- automotive-website
- legal-website
- food-website

To publish one site independently, upload only that site's folder contents to its own GitHub repository and enable GitHub Pages. The directory page links between folders only when the whole collection is published together in one repository. It is not required for the individual sites to work.

These are front-end demo sites. Enquiry forms, bookings, payment processing, authentication and database-backed features require backend integration before production use.
